# 自分のレビュー一覧画面

Phase1では、ログイン済みユーザーが自分の投稿したレビューを一覧で確認し、下書きレビューの編集と自分のレビュー削除を行える画面を用意する。

```txt
マイページ
↓
自分のレビュー一覧
↓
商品詳細

自分のレビュー一覧
↓
レビュー編集
```

---

## 共通方針

- Browser から Go API を直接呼び出さない
- 自分のレビュー管理は My Reviews BFF を利用する
- token は Browser JavaScript で保持しない
- 認証が必要な取得では refresh retry を適用する
- backend の HTTP status / error code を BFF でも維持する
- rating/statusフィルタ、ページネーション、レビュー詳細画面は扱わない

---

## My Reviews BFF

frontend BFF:

```txt
GET /api/me/reviews
GET /api/me/reviews/:id
PATCH /api/me/reviews/:id
DELETE /api/me/reviews/:id
```

backend:

```txt
GET /api/me/reviews
GET /api/me/reviews/:id
PATCH /api/me/reviews/:id
DELETE /api/me/reviews/:id
```

BFF は `access_token` cookie を利用して backend API を呼び出す。
401 の場合は `refresh_token` cookie による refresh retry を行う。

## 自分のレビュー一覧画面

Path:

```txt
/me/reviews
```

### 表示内容

- 商品名
- rating
- title
- comment
- status
- createdAt
- updatedAt
- 商品詳細への導線
- 編集導線
- 削除ボタン

### status表示

APIの status はユーザー向け表示名に変換する。

| API値 | 表示名 |
| --- | --- |
| `draft` | 下書き |
| `published` | 公開中 |
| `hidden` | 非表示 |

### title / comment

- `title` が `null` または空文字の場合は未入力表示にする
- `comment` が `null` または空文字の場合は未入力表示にする
- comment はプレーンテキストとして表示する

### 取得

画面表示時に My Reviews BFF の `GET /api/me/reviews` からレビュー一覧を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- レビュー0件の場合は空状態と注文履歴への導線を表示する
- 未ログインの場合は `/login?returnTo=%2Fme%2Freviews` へ遷移する

---

## 自分のレビュー編集画面

Path:

```txt
/me/reviews/:id/edit
```

### 表示内容

- 対象商品名
- rating
- title
- comment
- 保存ボタン
- 一覧へ戻る導線

### 編集ルール

- 編集対象は `draft` のレビューのみ
- `published` / `hidden` のレビューへ直接アクセスした場合は、編集フォームを表示せず編集不可メッセージを表示する
- rating は 1〜5 の整数を必須にする
- title / comment は任意入力にする
- comment がある場合は title 必須にする
- title / comment は送信前に trim し、空文字は `null` として送る

### 取得・保存

- 画面表示時に My Reviews BFF の `GET /api/me/reviews/:id` からレビュー詳細を取得する
- 保存時は My Reviews BFF の `PATCH /api/me/reviews/:id` へ rating / title / comment を送る
- 保存成功時は成功メッセージを表示し、返却されたレビューでフォームを更新する
- validation error はフォーム内に表示する
- 未ログインの場合は `/login?returnTo=%2Fme%2Freviews%2F:id%2Fedit` へ遷移する

---

## 自分のレビュー削除

- 一覧の各レビューに削除ボタンを表示する
- 削除前に確認ダイアログを表示する
- 削除確定時は My Reviews BFF の `DELETE /api/me/reviews/:id` を呼び出す
- 削除成功時は一覧から対象レビューを取り除き、成功メッセージを表示する
- 削除後に0件になった場合は空状態と注文履歴への導線を表示する
- 削除失敗時は対象レビューにエラーを表示する
- Phase1では自分のレビューなら status に関係なく削除可能にする

---

## 画面導線

- マイページから自分のレビュー一覧へ進める
- 自分のレビュー一覧から商品詳細へ進める
- 自分のレビュー一覧から下書きレビューの編集画面へ進める
- レビュー編集画面から自分のレビュー一覧へ戻れる

---

## E2E確認観点

- マイページから自分のレビュー一覧へ遷移できる
- ログイン済みユーザーが自分のレビュー一覧を表示できる
- `draft` / `published` / `hidden` のレビューが表示される
- status がユーザー向け表示名に変換される
- title / comment がないレビューでも表示できる
- レビュー0件の場合に空状態と注文履歴導線が表示される
- API error時に取得失敗表示と再読み込み導線が表示される
- 下書きレビューに編集導線が表示される
- 公開中・非表示レビューは編集不可として表示される
- 下書きレビューを編集して保存できる
- comment のみ入力した編集は保存前に validation error になる
- 公開中・非表示レビューの編集URLへ直接遷移してもフォームを表示しない
- レビュー削除を確定すると一覧から対象レビューが消える
- レビュー削除をキャンセルすると削除APIを呼ばない
- レビュー削除失敗時に対象レビューへエラーを表示する
- 未ログイン時に returnTo 付きでログインへ遷移する
