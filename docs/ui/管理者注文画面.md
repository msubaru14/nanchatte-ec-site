# 管理者注文画面

Phase1では、admin role を持つ管理者が全ユーザーの注文を一覧で確認し、注文詳細を参照し、必要に応じて注文をキャンセルできる画面を用意する。

```txt
管理者トップ
↓
管理者注文一覧
↓
管理者注文詳細
```

---

## 共通方針

- Browser から Go API を直接呼び出さない
- 管理者注文管理は Admin Order BFF を利用する
- token は Browser JavaScript で保持しない
- 認証が必要な取得・更新では refresh retry を適用する
- backend の HTTP status / error code を BFF でも維持する
- Phase1では検索・フィルタ、ページネーション、キャンセル理由入力は扱わない

---

## Admin Order BFF

frontend BFF:

```txt
GET /api/admin/orders
GET /api/admin/orders/:id
POST /api/admin/orders/:id/cancel
```

backend:

```txt
GET /api/admin/orders
GET /api/admin/orders/:id
POST /api/admin/orders/:id/cancel
```

BFF は `access_token` cookie を利用して backend API を呼び出す。
401 の場合は `refresh_token` cookie による refresh retry を行う。

---

## 管理者注文一覧画面

Path:

```txt
/admin/orders
```

### 表示内容

- orderId
- orderNumber
- userId
- userName
- userEmail
- status
- totalAmount
- orderedAt
- canceledAt
- 注文詳細への導線

### status表示

APIの status は管理者向け表示名に変換する。

| API値 | 表示名 |
| --- | --- |
| `ordered` | 注文済み |
| `canceled` | キャンセル済み |

### 取得

画面表示時に Admin Order BFF の `GET /api/admin/orders` から注文一覧を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- 注文0件の場合は空状態を表示する
- 未ログインの場合は `/admin/login?returnTo=%2Fadmin%2Forders` へ遷移する
- admin role がない場合は権限エラーとして表示する

---

## 管理者注文詳細画面

Path:

```txt
/admin/orders/:id
```

### 表示内容

- orderId
- orderNumber
- userId
- userName
- userEmail
- status
- totalAmount
- orderedAt
- canceledAt
- order_items の注文時点スナップショット
- 管理者注文一覧への導線
- キャンセルボタン

### 注文明細

- productId
- productName
- maker
- modelNumber
- productImageUrl
- unitPrice
- quantity
- lineTotal

`maker` / `modelNumber` / `productImageUrl` が `null` の場合も、画面が崩れない表示にする。

### 取得

画面表示時に Admin Order BFF の `GET /api/admin/orders/:id` から注文詳細を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- 対象注文が存在しない場合は Not Found 表示にする
- 未ログインの場合は `/admin/login?returnTo=` に実際の注文IDを含む `/admin/orders/:id` を URL encode して遷移する
- admin role がない場合は権限エラーとして表示する

---

## 注文キャンセル

- 対象は `ordered`
- 操作前に確認ダイアログを表示する
- 確定時は Admin Order BFF の `POST /api/admin/orders/:id/cancel` を呼び出す
- 成功時は返却された注文で詳細表示を更新し、成功メッセージを表示する
- 失敗時は詳細画面内にエラーを表示する
- `canceled` にはキャンセルボタンを表示しない
- 再キャンセルなどの業務エラーは `CONFLICT` として表示する

---

## 画面導線

- 管理者トップの「注文管理」から管理者注文一覧へ進める
- 管理者注文一覧から管理者注文詳細へ進める
- 管理者注文詳細から管理者注文一覧へ戻れる

---

## E2E確認観点

- adminユーザーが管理者注文一覧を表示できる
- `ordered` / `canceled` の注文が表示される
- status が管理者向け表示名に変換される
- 注文0件の場合に空状態が表示される
- 一覧取得失敗時にエラーと再読み込み導線が表示される
- 管理者トップから注文管理へ遷移できる
- 管理者注文一覧から注文詳細へ遷移できる
- adminユーザーが管理者注文詳細を表示できる
- 注文明細の注文時点スナップショットが表示される
- `maker` / `modelNumber` / `productImageUrl` がない明細でも表示できる
- 対象注文が存在しない場合は Not Found 表示になる
- 詳細取得失敗時にエラーと再読み込み導線が表示される
- ordered 注文をキャンセルできる
- canceled 注文ではキャンセルボタンを表示しない
- 操作キャンセル時はAPIを呼ばず状態も変わらない
- キャンセル失敗時にエラーが表示される
- 未ログイン時に returnTo 付きで管理者ログインへ遷移する
- customerユーザーは権限エラーとして扱われる

---

## 対象外

- backend Admin Order API
- 検索 / フィルタ
- ページネーション
- キャンセル理由入力
- 配送・決済・メール送信
- 管理者操作ログ
