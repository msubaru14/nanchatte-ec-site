# 注文導線画面

Phase1では、Cartから注文確認画面へ進み、注文確定後に注文完了画面へ到達できる導線を提供する。

```txt
Cart
↓
注文確認
↓
注文確定
↓
注文完了
```

---

## 共通方針

- Browser から Go API を直接呼び出さない
- Cart取得は Cart BFF を利用する
- 注文確定は Order BFF の `POST /api/orders` を利用する
- token は Browser JavaScript で保持しない
- 注文履歴一覧・注文詳細は [注文履歴画面](./注文履歴画面.md) で扱う
- 決済・配送・CheckoutSession は扱わない

---

## Cart画面から注文確認への導線

Cart画面の合計エリアに注文確認画面への導線を表示する。

- Cartが空の場合は注文確認へ進めない
- 数量変更が未反映の場合は注文確認へ進めない
- 未反映数量がある場合は「料金を再計算」で反映してから進む
- Cart操作中は注文確認へ進めない

遷移先:

```txt
/orders/confirm
```

---

## 注文確認画面

Path:

```txt
/orders/confirm
```

### 表示内容

- CartItem一覧
- 商品名
- 商品画像またはNo Image表示
- 在庫状態
- 単価
- 数量
- 小計
- 合計金額
- Cartへ戻る導線
- 注文確定ボタン

### Cart取得

画面表示時に Cart BFF からCart内容を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- 未ログインの場合は `/login?returnTo=%2Forders%2Fconfirm` へ遷移する
- 空Cartの場合は空Cart表示にし、商品一覧への導線を表示する

### 購入不可商品の扱い

Cart内に購入不可商品が含まれる場合:

- 商品行に購入不可メッセージを表示する
- 合計エリアにも確認メッセージを表示する
- 注文確定ボタンを disabled にする
- Cartへ戻って内容を確認できる導線を表示する

---

## 注文確定

注文確定ボタン押下時に、Order BFF の `POST /api/orders` を呼び出す。

- request body は持たない
- 送信中は注文確定ボタンを disabled にする
- 二重送信を防止する
- 成功時は注文結果を一時保存し、注文完了画面へ遷移する
- 注文成功後はHeaderのCart件数を更新する

成功時遷移先:

```txt
/orders/complete
```

### 注文確定エラー

| error code | 表示・導線 |
| --- | --- |
| `EMPTY_CART` | 空Cart表示に切り替え、Cartへ戻る導線と商品一覧導線を表示する |
| `OUT_OF_STOCK` | 在庫不足メッセージを表示し、Cartを再取得して最新状態を表示する |
| `VALIDATION_ERROR` | 販売停止などの注文不可メッセージを表示し、Cartを再取得して最新状態を表示する |
| `UNAUTHORIZED` | `/login?returnTo=%2Forders%2Fconfirm` へ遷移する |

---

## 注文完了画面

Path:

```txt
/orders/complete
```

### 表示内容

- 注文完了メッセージ
- 注文番号
- 合計金額
- 注文詳細へ進む導線
- 注文履歴へ進む導線
- 商品一覧へ戻る導線
- Cartへ戻る導線

### 注文結果の扱い

Phase1では、注文完了画面で注文詳細をbackendから永続取得しない。

- 注文確定成功時のレスポンスを `sessionStorage` に一時保存する
- 注文完了画面は一時保存された注文結果を表示する
- リロードなどで注文結果が取得できない場合は、案内メッセージと戻り導線を表示する
- 注文完了直後は一時保存された `orderId` を使い、注文履歴詳細へ進める
- 注文履歴一覧・注文詳細画面では、BFF経由でbackendから永続化された注文履歴を取得する

---

## E2E確認観点

- Cartから注文確認へ進める
- 注文確認でCart内容と合計金額を確認できる
- 未反映数量がある場合は注文確認へ進めない
- 注文確定成功時に注文完了画面へ遷移する
- 注文完了画面に注文番号と合計金額が表示される
- 注文完了画面から注文詳細・注文履歴へ進める
- 注文成功後にHeaderのCart件数が更新される
- `EMPTY_CART` の主要ケースを表示できる
- `OUT_OF_STOCK` の主要ケースを表示できる
