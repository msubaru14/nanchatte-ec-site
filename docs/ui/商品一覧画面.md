# 商品一覧画面

## 目的

一般ユーザーが公開中の商品を一覧で閲覧できる画面。

Phase1では、検索・絞り込み・並び替え・ページネーションは扱わず、Product一覧APIから取得した商品をカード形式で表示する。

---

## URL

```txt
/products
```

---

## 利用API

```txt
GET /api/products
```

- `status = active` の商品のみ表示対象
- 在庫0商品も表示対象
- `stockQuantity` は表示しない
- 税込価格 `priceIncludingTax` を表示する

---

## 表示内容

### ページ

- 画面タイトル
- 商品件数
- 商品一覧
- 0件時メッセージ
- loading表示
- error表示

### 商品カード

- 商品画像
  - `imageUrl` がない場合は placeholder を表示する
- 商品名
- メーカー名
  - 未設定の場合は「メーカー未設定」を表示する
- 税込価格
  - 価格の後ろに `(税込)` を表示する
- カテゴリ
- 在庫状態

---

## 在庫状態表示

| API値 | 表示 |
| --- | --- |
| `in_stock` | 在庫あり |
| `low_stock` | 残りわずか |
| `out_of_stock` | 在庫なし |

---

## 導線

商品カード全体をクリック可能にし、商品詳細URLへ遷移する。

```txt
/products/{id}
```

商品詳細画面本体は後続Issueで実装する。

---

## レスポンシブ方針

- PCでは商品カードを3〜4列程度で表示する
- タブレットでは2列程度で表示する
- スマホでは1列で表示する
- スマホではカードをややコンパクトに表示する
- 横スクロールを発生させない
- 長い商品名・メーカー名でもカード幅を突き破らない

---

## エラー・ローディング

### loading

- 商品カード型の skeleton を表示する

### error

- 商品一覧を取得できなかった旨を表示する
- 再読み込みボタンを表示する

---

## 対象外

- Cart追加
- お気に入り
- 検索
- 絞り込み
- pagination
- sort
- 商品詳細画面本体
- レビュー表示
- Admin Layout / Header
