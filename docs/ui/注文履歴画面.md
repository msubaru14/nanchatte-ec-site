# 注文履歴画面

Phase1では、注文確定済みのOrderを後から確認できるようにする。

```txt
マイページ / 注文完了
↓
注文履歴一覧
↓
注文履歴詳細
```

---

## 共通方針

- Browser から Go API を直接呼び出さない
- 注文履歴取得は Order BFF を利用する
- token は Browser JavaScript で保持しない
- 認証が必要な取得では refresh retry を適用する
- backend の HTTP status / error code を BFF でも維持する
- 決済・配送・注文キャンセルは扱わない
- 検索・絞り込み・ページネーション本格対応は扱わない

---

## Order BFF

frontend BFF:

```txt
GET /api/orders
GET /api/orders/:id
```

backend:

```txt
GET /api/orders
GET /api/orders/:id
```

BFF は `access_token` cookie を利用して backend API を呼び出す。
401 の場合は `refresh_token` cookie による refresh retry を行う。

---

## 注文履歴一覧画面

Path:

```txt
/orders
```

### 表示内容

- 注文番号
- 注文日時
- 注文ステータス
- 商品数
- 合計金額
- 詳細画面への導線

### 取得

画面表示時に Order BFF の `GET /api/orders` から注文履歴を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- 注文0件の場合は空状態と商品一覧への導線を表示する
- 未ログインの場合は `/login?returnTo=%2Forders` へ遷移する

---

## 注文履歴詳細画面

Path:

```txt
/orders/:id
```

### 表示内容

注文概要:

- 注文番号
- 注文日時
- 注文ステータス
- 税抜合計
- 消費税合計
- 税込合計

注文明細:

- 商品名
- 商品画像またはNo Image表示
- メーカー名
- 型番
- 税抜単価
- 税率
- 税込単価
- 数量
- 税抜小計
- 消費税小計
- 税込小計
- 商品詳細画面のレビュー投稿フォームへの導線

### 取得

画面表示時に Order BFF の `GET /api/orders/:id` から注文詳細を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- `NOT_FOUND` の場合は「注文が見つかりませんでした。」を表示する
- `INVALID_REQUEST` の場合は「不正な注文IDです。」を表示する
- `NOT_FOUND` / `INVALID_REQUEST` では注文履歴一覧へ戻る導線を表示する
- 未ログインの場合は `/login?returnTo=%2Forders%2F{id}` へ遷移する

---

## 画面導線

- マイページから注文履歴一覧へ進める
- 注文完了画面から注文履歴詳細へ進める
- 注文完了画面から注文履歴一覧へ進める
- 注文履歴詳細から注文履歴一覧へ戻れる
- 注文履歴詳細の商品ごとに `/products/{productId}?review=1` へ進める

---

## E2E確認観点

- 注文履歴一覧を表示できる
- 一覧から詳細へ遷移できる
- 詳細で注文時点のスナップショットを確認できる
- 注文0件でも破綻しない
- 未ログイン時に returnTo 付きでログインへ遷移する
- 存在しない注文で案内表示になる
- 注文履歴詳細の商品からレビュー投稿導線へ進める
