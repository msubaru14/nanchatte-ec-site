# 管理者レビュー一覧画面

Phase1では、admin role を持つ管理者が全ユーザーのレビューを一覧で確認し、問題のあるレビューを非表示化し、必要に応じて再公開できる画面を用意する。

```txt
Header
↓
管理者レビュー一覧
↓
商品詳細
```

---

## 共通方針

- Browser から Go API を直接呼び出さない
- 管理者レビュー管理は Admin Review BFF を利用する
- token は Browser JavaScript で保持しない
- 認証が必要な取得・更新では refresh retry を適用する
- backend の HTTP status / error code を BFF でも維持する
- Phase1ではレビュー詳細画面、ページネーション、rating/statusフィルタは扱わない

---

## Admin Review BFF

frontend BFF:

```txt
GET /api/admin/reviews
POST /api/admin/reviews/:id/hide
POST /api/admin/reviews/:id/publish
```

backend:

```txt
GET /api/admin/reviews
POST /api/admin/reviews/:id/hide
POST /api/admin/reviews/:id/publish
```

BFF は `access_token` cookie を利用して backend API を呼び出す。
401 の場合は `refresh_token` cookie による refresh retry を行う。

## 管理者レビュー一覧画面

Path:

```txt
/admin/reviews
```

### 表示内容

- reviewId
- userId
- reviewerName
- productId
- productName
- rating
- title
- comment
- status
- createdAt
- updatedAt
- 商品詳細への導線
- 非表示化ボタン
- 再公開ボタン

### status表示

APIの status は管理者向け表示名に変換する。

| API値 | 表示名 |
| --- | --- |
| `draft` | 下書き |
| `published` | 公開中 |
| `hidden` | 非表示 |

### title / comment

- `title` が `null` または空文字の場合は未入力表示にする
- `comment` が `null` または空文字の場合は未入力表示にする
- comment はプレーンテキストとして表示する

### 取得

画面表示時に Admin Review BFF の `GET /api/admin/reviews` からレビュー一覧を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- レビュー0件の場合は空状態を表示する
- 未ログインの場合は `/login?returnTo=%2Fadmin%2Freviews` へ遷移する
- admin role がない場合は権限エラーとして表示する

---

## レビュー操作

### 非表示化

- 対象は `published` / `draft`
- 操作前に確認ダイアログを表示する
- 確定時は Admin Review BFF の `POST /api/admin/reviews/:id/hide` を呼び出す
- 成功時は返却されたレビューで一覧内の対象レビューを更新し、成功メッセージを表示する
- 失敗時は対象レビュー付近にエラーを表示する

### 再公開

- 対象は `hidden`
- 操作前に確認ダイアログを表示する
- 確定時は Admin Review BFF の `POST /api/admin/reviews/:id/publish` を呼び出す
- 成功時は返却されたレビューで一覧内の対象レビューを更新し、成功メッセージを表示する
- 失敗時は対象レビュー付近にエラーを表示する

### 操作不可表示

- `published` / `draft` には再公開ボタンを表示しない
- `hidden` には非表示化ボタンを表示しない

---

## 画面導線

- admin role を持つログインユーザーには Header にレビュー管理導線を表示する
- customer ユーザーには Header のレビュー管理導線を表示しない
- 管理者レビュー一覧から商品詳細へ進める

---

## E2E確認観点

- adminユーザーが管理者レビュー一覧を表示できる
- `draft` / `published` / `hidden` のレビューが表示される
- status が管理者向け表示名に変換される
- title / comment がないレビューでも表示できる
- レビュー0件の場合に空状態が表示される
- publishedレビューを非表示にできる
- draftレビューを非表示にできる
- hiddenレビューを再公開できる
- 操作キャンセル時はAPIを呼ばず状態も変わらない
- 操作失敗時にエラーが表示される
- 一覧取得失敗時にエラーと再読み込み導線が表示される
- 未ログイン時に returnTo 付きでログインへ遷移する
- customerユーザーは権限エラーとして扱われる
- adminユーザーには Header にレビュー管理導線が表示される
- customerユーザーには Header にレビュー管理導線が表示されない
