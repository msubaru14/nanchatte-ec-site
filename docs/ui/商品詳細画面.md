# 商品詳細画面

## 目的

一般ユーザーが公開中の商品情報を確認し、数量を指定して Cart へ追加できる画面。

Phase1では、商品詳細APIから在庫状態を取得して表示し、Cart追加時の最終在庫チェックは Cart API に委ねる。

---

## URL

```txt
/products/{id}
```

---

## 利用API

```txt
GET  /api/products/{id}
POST /api/cart/items
```

### 商品詳細取得

- `status = active` の商品だけを表示対象とする
- 販売停止商品、存在しない商品は Not Found 扱いとする
- 税込価格 `priceIncludingTax` を表示する
- 在庫数そのものは表示せず、`stockStatus` のみを表示する
- 公開APIであるため、`maxSelectableQuantity` は返さない

### Cart追加

- Browser から backend API を直接呼ばず、Next.js Route Handler の Cart BFF を経由する
- `productId` と画面で選択した `quantity` を送信する
- 認証 token は Browser JavaScript で保持しない

---

## 表示内容

- 商品画像
  - `imageUrl` がない場合は placeholder を表示する
- カテゴリ
- 在庫状態
- 商品名
- 税込価格
- メーカー名
  - 未設定の場合は「メーカー未設定」を表示する
- 型番
  - 設定されている場合のみ表示する
- 発売日
  - 設定されている場合のみ表示する
- 商品説明
  - 未設定の場合は「商品説明はありません」を表示する
- 商品一覧へ戻る導線

---

## 在庫状態表示

| API値 | 表示 | Cart追加 |
| --- | --- | --- |
| `in_stock` | 在庫あり | 操作可能 |
| `low_stock` | 残りわずか | 操作可能 |
| `out_of_stock` | 在庫なし | 操作不可 |

---

## Cart追加エリア

### 数量指定

- 数量はステッパー方式で指定する
- 初期値は `1` とする
- `+` / `-` の操作では画面ローカル state のみを変更し、API は呼び出さない
- 数量は `1` 未満にできない
- 商品詳細APIから最大選択可能数は取得しないため、画面上で在庫上限による `+` の停止は行わない
- 在庫なし商品では `+` / `-` の操作を disabled にする

### 追加ボタン

- 「カートに追加」ボタン押下時のみ Cart追加APIを呼び出す
- 追加中はボタンと数量操作を disabled にし、二重送信を防ぐ
- 在庫なし商品では追加ボタンを disabled にし、「在庫なし」と表示する

---

## 成功時導線

- Cart追加に成功した場合、「カートに追加しました。」を表示する
- `/cart` へ移動できる「カートを見る」導線を表示する
- 商品詳細画面には留まり、同じ商品の追加操作を継続できる

---

## 未ログイン時の導線

Cart追加APIが `UNAUTHORIZED` を返した場合:

- `AuthContext` の user を未ログイン状態へ更新する
- ログイン画面へ遷移する
- `returnTo` には現在の商品詳細URLを設定する

```txt
/login?returnTo=%2Fproducts%2F{id}
```

ログイン後は商品詳細画面へ戻り、改めてCart追加操作を行える。

---

## 在庫不足時の導線

商品詳細画面の表示後に在庫が変動する可能性があるため、最終在庫チェックは `POST /api/cart/items` で行う。

Cart追加APIが `OUT_OF_STOCK` を返した場合、`details.availableQuantity` を利用する。

### 追加可能数量がある場合

以下の確認ダイアログを表示する。

```txt
在庫が不足しています。
購入可能な最大数量({availableQuantity}個)でカートへ追加しますか？
```

- 承諾した場合は、`quantity = availableQuantity` として Cart追加APIを一度再実行する
- キャンセルした場合は、商品詳細画面に留まり、入力数量を維持する

### 追加可能数量が0の場合

- 再追加の確認は行わない
- 在庫がないため追加できなかった旨を表示する

### `availableQuantity` の意味

- 商品がすでに Cart に存在する場合も考慮した、今回さらに追加可能な数量である
- 商品詳細APIで公開される在庫情報ではなく、認証済みの Cart追加操作が在庫不足になった場合にのみ返される

---

## その他のエラー表示

- `VALIDATION_ERROR` の場合は、この商品をCartに追加できない旨を表示する
- その他のAPI errorまたは通信失敗の場合は、Cart追加に失敗した旨を表示する
- エラー表示後も画面を壊さず、数量調整や再操作を継続できる

---

## loading / error / Not Found

### loading

- 商品詳細レイアウトに合わせた skeleton を表示する

### error

- 商品情報を取得できなかった旨を表示する
- 再読み込み操作を表示する

### Not Found

- 存在しない商品、または一般ユーザーが閲覧できない販売停止商品は Not Found 表示とする

---

## レスポンシブ方針

- desktop では商品画像と商品情報を横並びで表示する
- 狭い画面では縦並びに切り替える
- Cart追加エリアはスマホでは利用可能幅に合わせて表示する
- 長い商品名や説明文でも横スクロールを発生させない

---

## 対象外

- 商品詳細APIでの `maxSelectableQuantity` 返却
- 未ログインCart
- Header の Cart件数表示
- optimistic update
- グローバルCart state
- Order / 注文確認導線
