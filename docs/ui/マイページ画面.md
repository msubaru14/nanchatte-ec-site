# マイページ画面

Phase1では、ログイン済みユーザー向けの導線をHeaderに増やしすぎないため、マイページを入口として用意する。

```txt
Headerのユーザー名
↓
マイページ
↓
注文履歴 / 自分のレビュー一覧
```

---

## 共通方針

- Headerではログイン中ユーザーの表示名を `/me` へのリンクとして表示する
- ユーザー向け機能の導線はマイページへ集約する
- Browser から Go API を直接呼び出さない
- 認証状態は `AuthContext` と `GET /api/auth/me` の復元結果を利用する
- token は Browser JavaScript で保持しない

---

## マイページ

Path:

```txt
/me
```

### 表示内容

- 画面タイトル
- ログイン中ユーザーの表示名
- 注文履歴への導線
- 自分のレビュー一覧への導線

### 認証状態

- 認証状態確認中は読み込み中表示を行う
- 未ログインの場合は `/login?returnTo=%2Fme` へ遷移する

---

## 画面導線

- Headerのログイン中ユーザー名からマイページへ進める
- マイページから注文履歴一覧へ進める
- マイページから自分のレビュー一覧へ進める

---

## E2E確認観点

- Headerのユーザー名からマイページへ進める
- マイページに注文履歴への導線が表示される
- マイページに自分のレビュー一覧への導線が表示される
- 自分のレビュー一覧へ遷移できる
- 未ログイン時に returnTo 付きでログインへ遷移する
