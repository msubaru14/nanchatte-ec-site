# 管理者商品一覧画面

Phase1では、admin role を持つ管理者が商品一覧を確認し、商品の新規登録・編集・販売停止・販売再開を操作できる画面を用意する。

```txt
管理者トップ
↓
管理者商品一覧
↓
商品登録 / 商品編集
↓
商品詳細
```

---

## 共通方針

- Browser から Go API を直接呼び出さない
- 管理者商品管理は Admin Product BFF を利用する
- token は Browser JavaScript で保持しない
- 認証が必要な取得・更新では refresh retry を適用する
- backend の HTTP status / error code を BFF でも維持する
- Phase1では管理者商品詳細画面、検索・フィルタ、ページネーションは扱わない

---

## Admin Product BFF

frontend BFF:

```txt
GET /api/admin/products
GET /api/admin/products/:id
POST /api/admin/products
PATCH /api/admin/products/:id
POST /api/admin/products/:id/stop-selling
POST /api/admin/products/:id/resume-selling
```

backend:

```txt
GET /api/admin/products
GET /api/admin/products/:id
POST /api/admin/products
PATCH /api/admin/products/:id
POST /api/admin/products/:id/stop-selling
POST /api/admin/products/:id/resume-selling
```

BFF は `access_token` cookie を利用して backend API を呼び出す。
401 の場合は `refresh_token` cookie による refresh retry を行う。

## 管理者商品一覧画面

Path:

```txt
/admin/products
```

### 表示内容

- productId
- name
- description
- price
- taxRate
- taxRateId
- categoryId
- stockQuantity
- lowStockThreshold
- 在庫状態
- status
- createdAt
- updatedAt
- 商品詳細への導線
- 商品登録への導線
- 商品編集への導線
- 販売停止ボタン
- 販売再開ボタン

### status表示

APIの status は管理者向け表示名に変換する。

| API値 | 表示名 |
| --- | --- |
| `active` | 販売中 |
| `stopped` | 販売停止 |

### description

- `description` が `null` または空文字の場合は未入力表示にする
- description はプレーンテキストとして表示する

### 在庫状態

backend から stock status が返らないため、frontend 側で以下のように表示する。

| 条件 | 表示名 |
| --- | --- |
| `stockQuantity === 0` | 在庫なし |
| `stockQuantity <= lowStockThreshold` | 残りわずか |
| 上記以外 | 在庫あり |

### 取得

画面表示時に Admin Product BFF の `GET /api/admin/products` から商品一覧を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- 商品0件の場合は空状態を表示する
- 未ログインの場合は `/admin/login?returnTo=%2Fadmin%2Fproducts` へ遷移する
- admin role がない場合は権限エラーとして表示する

## 商品登録画面

Path:

```txt
/admin/products/new
```

### 入力項目

- name
- description
- price
- taxRateId
- categoryId
- stockQuantity
- lowStockThreshold
- status

登録時の `status` は `active` / `stopped` を選択できる。
初期値は `active` とする。

### 登録

- 送信時は Admin Product BFF の `POST /api/admin/products` を呼び出す
- description 空欄は `null` として扱う
- stockQuantity = 0 / lowStockThreshold = 0 を許容する
- 成功時は `/admin/products?message=created` へ遷移し、一覧画面で成功メッセージを表示する
- validation error は form 全体と field 単位で表示する
- 401 の場合は `/admin/login?returnTo=%2Fadmin%2Fproducts%2Fnew` へ遷移する
- 403 の場合は権限エラーを表示する

---

## 商品編集画面

Path:

```txt
/admin/products/:id/edit
```

### 入力項目

- name
- description
- price
- taxRateId
- categoryId
- stockQuantity
- lowStockThreshold

編集画面では `status` を直接編集しない。
販売停止・販売再開は管理者商品一覧画面の専用操作で行う。

### 取得

画面表示時に Admin Product BFF の `GET /api/admin/products/:id` から対象商品を取得する。

- loading中は読み込み中表示を行う
- 取得失敗時はエラー表示と再読み込み導線を表示する
- 商品が存在しない場合は Not Found 表示にする
- 未ログインの場合は `/admin/login?returnTo=` に実際の商品IDを含む `/admin/products/:id/edit` を URL encode して遷移する
- admin role がない場合は権限エラーとして表示する

### 編集

- 送信時は Admin Product BFF の `PATCH /api/admin/products/:id` を呼び出す
- description 空欄は `null` として扱う
- stockQuantity = 0 / lowStockThreshold = 0 を許容する
- 成功時は `/admin/products?message=updated` へ遷移し、一覧画面で成功メッセージを表示する
- validation error は form 全体と field 単位で表示する
- 401 の場合は returnTo 付きで管理者ログインへ遷移する
- 403 の場合は権限エラーを表示する

---

## 商品操作

### 販売停止

- 対象は `active`
- 操作前に確認ダイアログを表示する
- 確定時は Admin Product BFF の `POST /api/admin/products/:id/stop-selling` を呼び出す
- 成功時は返却された商品で一覧内の対象商品を更新し、成功メッセージを表示する
- 失敗時は対象商品付近にエラーを表示する

### 販売再開

- 対象は `stopped`
- 操作前に確認ダイアログを表示する
- 確定時は Admin Product BFF の `POST /api/admin/products/:id/resume-selling` を呼び出す
- 成功時は返却された商品で一覧内の対象商品を更新し、成功メッセージを表示する
- 失敗時は対象商品付近にエラーを表示する

### 操作不可表示

- `active` には販売再開ボタンを表示しない
- `stopped` には販売停止ボタンを表示しない

## 画面導線

- 管理者トップの「商品管理」から管理者商品一覧へ進める
- 管理者商品一覧から一般ユーザー向けの商品詳細へ進める
- 管理者商品一覧から商品登録画面へ進める
- 管理者商品一覧から商品編集画面へ進める

## E2E確認観点

- adminユーザーが管理者商品一覧を表示できる
- `active` / `stopped` の商品が表示される
- status が管理者向け表示名に変換される
- description がない商品でも表示できる
- 在庫あり / 残りわずか / 在庫なし が表示される
- 商品0件の場合に空状態が表示される
- active 商品を販売停止にできる
- stopped 商品を販売再開できる
- 操作キャンセル時はAPIを呼ばず状態も変わらない
- 操作失敗時にエラーが表示される
- 一覧取得失敗時にエラーと再読み込み導線が表示される
- 未ログイン時に returnTo 付きで管理者ログインへ遷移する
- customerユーザーは権限エラーとして扱われる
- 管理者トップから商品管理へ遷移できる
- 管理者商品一覧から商品登録画面へ遷移できる
- 管理者商品一覧から商品編集画面へ遷移できる
- adminユーザーが商品登録できる
- adminユーザーが商品編集できる
- 商品登録時に active / stopped を選択できる
- 商品編集画面では status を直接変更しない
- description 空欄でも登録・編集できる
- stockQuantity = 0 / lowStockThreshold = 0 でも登録・編集できる
- validation error が表示される
- 商品取得失敗時にエラーと再読み込み導線が表示される
- 存在しない商品IDでは Not Found 表示になる
- 商品登録 / 編集画面の未ログイン時に returnTo 付きで管理者ログインへ遷移する
- 商品登録 / 編集画面で customerユーザーは権限エラーとして扱われる
